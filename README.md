### Instruções
#### Fluxo de uso:
1 Carregue a imagem original (jpg, jpeg, png ou bmp), se ela for colorida será transformada em escala de cinza<br>
2 Aperte o botão "Gerar Histograma" para gerar o histograma dela<br>
3 Aperte o botão "Equalizar" para equalizar<br>
4 Se quiser comparar a imagem e histogramas originais aperte em comparar<br>
5 Se quiser salvar, aperte o botão de salvar no canto superior direito<br>
<br><br>
A interface de Equalização Específica pode ser acessada por um botão no canto inferior direito<br>
1 Carregue a imagem original e a imnagem referência (seu histograma será considerado como referência para equalização da imagem original)<br>
2 Aperte o botão "Equalização Específica" para equalizar<br>
3 Se quiser salvar, aperte o botão de salvar no canto superior direito<br>
